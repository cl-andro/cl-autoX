# BuildCompat

![Maven Central](https://img.shields.io/maven-central/v/com.clauto.cl.buildcompat/buildcompat)

`com.clauto.buildcompat.BuildCompat`: Helper class that helps you to check Android version, but also naming in a different way (`atLeast13` ✓).

## Download

```groovy
dependencies {
    implementation "com.clauto.cl.buildcompat:buildcompat:<version>"
}
```

### Dependencies included (If you have concerns about file size)

- `androidx.annotation:annotation`
